# Hakamap iPhone版

React Native / Expoによる参照専用アプリです。0.1.2でExpo Go上の基本動作確認が完了しています。iPhoneの縦向きに対応します。
Windows版とは独立して起動し、通常の参照ではネットワークを使用しません。

## 起動

Node.js 24とnpmを使用します。SDK 58の公式テンプレートに合わせた依存を
`package-lock.json`に固定しています。

```bash
cd mobile
npm ci
npm start
```

対応するExpo Goまたは開発ビルドで確認してください。iOSシミュレーターのローカル起動は
macOSとXcodeのある環境で`npm run ios`を実行します。
署名済みアプリの生成にはEASプロジェクト設定とAppleの署名設定が別途必要です。
`app.json`のBundle Identifierは配布用アカウントで利用可能なものへ設定してからビルドします。
TestFlightへのアップロードやApple契約・署名設定はこの実装には含みません。

PCのExpo CLIとiPhoneのExpo Goは同じExpoアカウントにログインしてください。
Windowsでブラウザーの自動起動に失敗する場合は、`npx expo login --no-browser`で
Expoのユーザー名・パスワードを入力してから起動します。

## 0.1.2の修正

Expo Goで検索欄の`DomWebView`参照エラーが報告されたため、Expo DOMの表示エンジンを
既存依存の`react-native-webview`へ切り替えました。日本語変換確定の判定は維持します。
更新後はExpo Goを完全終了し、PCで`npm start -- --clear`を実行してから開き直してください。
取り込み済みデータの削除や再取り込み、依存の追加インストールは不要です。

## 0.1.1の変更

墓所をタップして墓所名・家名と人物氏名を確認できます。人名検索に一致する氏名は
「検索に一致」と表示します。既存の取り込み済みデータを使うため再取り込みは不要です。

## データの準備

Windows版の既存エクスポート機能で作成した`.hakamap`を、そのまま取り込みます。
Windows側の出力機能変更、専用形式、変換ツールは不要です。

1. Windows版で最新のデータを保存し、既存のエクスポートを実行します。
2. `.hakamap`をLINEや共有ドライブなどでiPhoneへ渡します。
3. iPhoneの「ファイル」に保存します。
4. アプリの「データを取り込む」で選択します。
5. データ登録済みの場合は置き換えを承認します。

- `manifest.json`、`project.json`、添付を含む全収録ファイルの整合性を検証します。
- 端末の参照DBへ保存するのは墓所名、人物氏名、配置図・エリア、必要な背景画像と作成日時です。
  添付、備考、戒名、元アーカイブは保存しません。取り込み用の一時コピーは処理後に削除します。
- 入力32MiB、展開合計48MiB、5,000墓所、20,000人物、背景4096px以下に対応します。
  上限を超える場合は取り込みを拒否し、既存データを保持します。
- WindowsバックアップZIPや非対応バージョンは受け入れません。
- 元のWindowsデータを変更することはありません。実データはGitへ追加しないでください。

## 実装範囲

- 初回取り込み案内、データ管理、作成日時、全件置換確認。
- ZIP構造・上限・SHA-256・JSON・ID・背景参照を検証してから保存。
- SQLiteの単一更新文で置き換え、SQL失敗時は旧データを保持。
- 墓所名・家名／人物氏名／すべての検索対象選択、部分一致、重複除去。
- 日本語変換の確定後に250msで検索。検索欄はローカル同梱のExpo DOMコンポーネントを使用。
- 全一致墓所の赤色強調、検索範囲への自動調整、0件・解除時のカメラ維持。
- React Native SVGによる配置図・背景、名前表示切替、全体表示、拡大縮小・ドラッグ。
- 名前表示設定を地図と別に保存。
- 墓所タップで人物氏名の一覧を参照。ドラッグや複数指操作では詳細を開かない。

## 検査

```bash
npm run typecheck
npm run lint
npm run format:check
npm test
npm run export:ios
```

`export:ios`はJavaScript・Hermesと検索欄のDOMバンドルの生成です。
署名済みIPAの生成、ネイティブコンパイル、実機での動作保証を意味しません。

実機で日本語キーボード、ピンチと指本数の切替、取り込み権限、バックグラウンド中断・
強制終了、容量不足、5,000墓所での描画性能、検索欄とキーボードの重なりを確認してください。
Windows版の検索対象選択は別途実装予定です。専用出力ボタンは不要になりました。
大型背景のタイル化はこの初期版に含まず、配布用アカウントの設定は別途必要です。
実機テストは[手順](../docs/verification/iphone.md)に沿って実施してください。
