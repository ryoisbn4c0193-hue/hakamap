# iPhone初期版の実機テスト

状態: 製造完了後の実機テスト待ち。下記は未実施の確認項目。

## 準備

[mobile README](../../mobile/README.md)に従い依存を導入し、`npm start`で開発用に起動する。
SDK 58に対応するExpo Go、またはEAS Buildで作成した実機用ビルドを使用する。
Expo Goで対応できない場合は`eas build --platform ios --profile preview`で実機用ビルドを用意する。
EASプロジェクト設定、Bundle Identifier、Apple署名設定は配布用アカウントで行う。
MacとXcodeがあれば`npm run ios`でシミュレーター確認も可能。

開発中のMetro接続には通信を使用する。オフライン参照の確認は、JS/DOMを同梱した
署名済みビルドで行い、開発サーバー接続の有無と混同しない。

Windows版で最新データを保存し、既存のエクスポートで`.hakamap`を作成する。
LINE・共有ドライブからiPhoneの「ファイル」へ保存する。変換は不要。
初期上限: ファイル32MiB・展開合計48MiB・背景4096px・5,000墓所・20,000人物。

## 確認項目

| 操作 | 期待結果 |
| --- | --- |
| 初回起動 | 取り込み案内が出る |
| `.hakamap`を選択 | Windowsと同じ配置・背景・墓所名で表示される |
| 取り込み後再起動 | データが残り、全体表示と空の検索欄で開く |
| 名前表示をオフにして再起動 | 非表示設定が保持される |
| 部分一致検索 | 該当するすべてのお墓が赤くなり、画面内に収まる |
| 対象を墓所名・人物氏名へ変更 | 指定した項目だけで検索する |
| 複数人物が同じ墓所で一致 | 件数は墓所1件として数える |
| 日本語変換中・確定 | 変換中は検索せず、確定後に更新する |
| キーボードを出して検索 | 操作欄やキーボードに一致墓所が隠れない |
| 検索解除・0件 | 強調や案内が適切に更新され、位置・倍率を維持する |
| 全体表示・＋・−・ピンチ・ドラッグ | 意図した位置・倍率で表示できる。指本数の変更で飛ばない |
| データ管理 | Windowsのエクスポート作成日時が表示される |
| 更新取り込みをキャンセル | 旧データのまま |
| 更新取り込みを承認 | 全件置き換わり、検索が解除されて全体表示になる |
| 破損・非対応版・上限超過 | エラーを表示し、旧データが残る |
| 取り込み中断・強制終了・容量不足 | 再起動後も旧データまたは正常に確定した新データを参照できる |
| 機内モードで起動・検索・移動 | 取り込み済みデータを参照できる（同梱ビルドで確認） |
| 最大規模のデータ | 起動・検索・操作が実用的な応答速度で動く |

添付・備考・戒名はiPhoneへ参照データとして保存しない。WindowsでPDFを背景にした場合は
エクスポートに含まれる変換済みPNGを表示する。
