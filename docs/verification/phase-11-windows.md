# Phase 11 Windows配布・性能・障害検証記録

最終更新日: 2026-07-30

## 判定

Phase 11は進行中である。Linux開発環境で配布構成と最小ランタイムを検証したが、
Windows 11実機、Windows用EXE、最低・推奨環境、外付け媒体、およびSMB 3.x共有の試験は
未実施であり、Phase完了またはリリース可能とは判定しない。

## Linux開発環境で確認済み

| 項目 | 結果 | 証跡・補足 |
| --- | --- | --- |
| Java 21 `jlink` | 成功 | 配布スクリプトと同じモジュールでランタイム生成 |
| 最小ランタイムのJAR読込 | 成功 | `java.instrument`不足を検出・追加後、Spring Boot起動まで確認 |
| ローカルHTTP初期化 | 成功 | Webサーバー初期化後、ヘッドレス環境のブラウザ起動で終了 |
| フロントエンド5,000墓所幾何 | 成功 | 日常テストで1秒未満の基準を検証 |
| Windowsビルドスクリプト設定 | 自動検査あり | ユーザー単位、ショートカット、固定UUID、主要モジュール、512MiB heap |
| 保存先機能検査 | スクリプト作成済み | 排他ロック、置換、同期読戻し、清掃。Windows媒体での実行は未実施 |
| Windows CI | Workflow作成済み・未実行 | EXE作成、Manifest SHA-256照合、7日間の成果物保存 |

ヘッドレスLinuxで既定ブラウザを開けない結果はWindows起動試験の代替ではない。
LinuxからWindows EXEをクロスビルドしていない。
