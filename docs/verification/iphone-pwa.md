# iPhone PWAの導入とオフライン確認

Apple Developer Program・Expo Go・Macは不要。iOS 17以降のSafariを目安に確認する。
初回導入とアプリ更新は通信が必要。取り込み済みデータの参照には通信を使わない。

- 配布パス`/hakamap/`でPWA生成に成功。
- Chromiumのモバイル・タッチ設定で2件のブラウザー検査が成功。

## 共通アイコンの配布データ確認（2026-10-27）

- 公開成功の実行39969647475（2026-10-23 23:26 JST開始、コミット02acd114）の配布Artifactを取得した。
- iPhone用180pxとPWA用192px・512pxが、Windows共通の原画像から生成したローカル画像とバイト一致。
- この公開用データをPCのChromiumで配信し、起動・オフライン準備完了・apple-touch-iconのHTTP読み込みと寸法を確認。
- 公開URLへの直接取得はこの環境の接続制限で未確認。配布履歴と配布用データの確認と区別する。
- iPhoneのホーム画面に登録済みのアイコンが変わったことは、PC検査だけでは保証しない。

  確認だけなら追加を確定する必要はなく、既存アプリを削除しない。
- アプリ削除やサイトデータ消去は取り込み済みデータを失う可能性があるため、アイコン確認の手順には含めない。

## 配布サイトの準備

GitHub Pagesを使う場合、公開するのは`mobile/dist-pwa/`のプログラムだけ。
実データの`.hakamap`を置かない。取り込んだ氏名・配置図・背景は端末内に保存する。

1. リポジトリのSettings → Pagesで、Build and deploymentのSourceを「GitHub Actions」にする。
2. Actionsの「iPhone PWAの検査・配布」を開く。
3. Run workflowで`publish`を有効にして実行する。
4. 成功後、deployジョブの公開URLをiPhoneへ渡す。

公開は手動実行した場合だけ行う。通常のpushでは検査と配布用Artifactの生成まで行う。
このリポジトリの標準公開先は`https://ryoisbn4c0193-hue.github.io/hakamap/`だが、
Pages設定・deployが終わるまでは利用できない。
このチャットのGitHub接続にはPages設定・ワークフローの手動実行ツールがないため、初回は利用者が行う。

## iPhoneへの追加

| 手順 | 操作 |
| --- | --- |
| 1 | 通信できる場所で、配布URLをSafariで開く。LINE内のブラウザーではなくSafariを使う |
| 2 | 「オフライン利用の準備完了」が表示されるまで待つ |
| 3 | Safariの共有メニューから「ホーム画面に追加」を選ぶ。項目がある場合は「Webアプリとして開く」を有効にする |
| 4 | Safariを閉じ、ホーム画面のHakamapアイコンから起動する |
| 5 | この画面でも「オフライン利用の準備完了」を確認する |
| 6 | Windowsで出力した既存`.hakamap`を「このiPhone内」など端末へダウンロード済みの場所に保存する |
| 7 | Hakamapの「データを取り込む」で選択する。Expo Goで取り込んだデータは自動では移らない |

[Windowsからの取り込み手順](../manuals/windows-to-iphone.md)はそのまま使用できる。
Safariで取り込んでもホーム画面側へ自動共有されるとは扱わず、ホーム画面から開いた後に取り込む。
ファイル選択をキャンセルした場合は元の画面に戻る。

ブラウザー自動検査の通信オフ試験は、iPhoneの実機試験完了を意味しない。

## 更新と保存の注意

- 通信できる状態で開き、更新がある場合は「更新を適用して再起動」を押す。取り込み中は押せない。
- 通常のアプリ更新で参照DBは削除しない。データ更新はWindowsから出力し直して取り込む。
- サイトデータ削除、ストレージの自動整理、ホーム画面からの削除などでデータが失われる場合がある。
  元の`.hakamap`は保管し、消えた場合は再取り込みする。
- プライベートブラウズは使わない。配布URLを変える場合は新しい場所で再取り込みが必要になることがある。
- 初回に「準備完了」にならないときは、通信と空き容量を確認して同じURLを開き直す。

## Windowsでのローカル検査

```powershell
cd D:\ChatGPT\hakamap\hakamap-iphone
git pull --ff-only
cd mobile
npm ci
npm run build:pwa
node scripts/serve-pwa.mjs
```

PCの`http://127.0.0.1:4173/`で確認できる。このアドレスはiPhoneからは開けない。
iPhoneのService WorkerにはHTTPSが必要なため、実機確認には配布URLを使う。
ホームページのファイルを「ファイル」アプリから直接開く方法ではPWAにならない。

```powershell
npx playwright install chromium
npm run test:pwa
```
