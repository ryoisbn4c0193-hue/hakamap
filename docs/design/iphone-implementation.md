## 技術方式と対応範囲

- Expo SDK 58 / React Native / TypeScript。依存をnpmロックファイルで固定する。
- 地図はReact Native SVG、操作はPanResponder、検索入力はローカル同梱のExpo DOM。
- 永続化はExpo SQLite。地図と背景は1レコードとして単一SQL文で全件置換し、
  旧行を手動で削除してから挿入する処理は行わない。表示設定は別に保存する。
- ZIPはfflate、境界検証はZod、SHA-256は@noble/hashes、画像寸法はimage-size。
- 既存エクスポートのマニフェストとプロジェクトの版、全収録ファイルのサイズ・ハッシュ、
  IDと参照を検証してから、墓所名・人物氏名・配置情報・参照背景だけを保存する。
- 添付・備考・戒名・元アーカイブは参照DBに保存しない。一時コピーは処理後に削除する。
- 初期上限は圧縮32MiB・展開48MiB・5,000墓所・20,000人物・背景4096px。
  座標は±1,000,000、寸法は正かつ1,000,000以下。超過時は明示的に拒否する。
- 大型背景のタイル化は今後の拡張であり、初期版は上限内の背景をそのまま描画する。
- Windowsの専用出力ボタンは不要。Windowsソースにデータ受け渡しの変更を加えていない。

SDK同梱の互換表を使用して依存を導入した。
