# WindowsからiPhoneへデータを取り込む

Windows版では上部の「操作ガイド」→「iPhoneへの取り込み」タブ、iPhone版では上部の「使い方」から、同じ手順を参照できます。

この手順はアプリに同梱され、外部サイトを開かずに読むことができます。

Windows版で管理している墓地をiPhoneで参照できます。既存のエクスポートファイル（.hakamap）をそのまま使い、変換操作は不要です。

起動URL: [Hakamap iPhone版](https://ryoisbn4c0193-hue.github.io/hakamap/)

iPhoneのSafariで開いてホーム画面に追加してください。PCでも同じURLで画面とアイコンを確認できます。

## 1. iPhone版をホーム画面に追加する

- 初回は通信できる場所で、HakamapのURL（https://ryoisbn4c0193-hue.github.io/hakamap/）をSafariで開きます。Appleの有料加入やExpo Goは不要です。
- 「オフライン利用の準備完了」を確認し、Safariの共有メニューから「ホーム画面に追加」を選びます。
- ホーム画面のHakamapアイコンから開き、準備完了を確認してから取り込みます。Expo Goで使っていたデータは取り込み直してください。

## 2. Windows版でエクスポートする

- 送りたい墓地プロジェクトを開き、最新の編集内容を保存します。
- 画面上部の「エクスポート」（下向き矢印のアイコン）を選び、保存先とファイル名を指定します。
- 出力が完了した.hakamapファイルを確認します。バックアップの.zipやproject.json単体は使用しません。

## 3. iPhoneの「ファイル」に保存する

- LINEや共有ドライブなどで、エクスポートした.hakamapファイルをiPhoneへ渡します。
- LINEで受け取った場合は添付ファイルを開き、共有メニューの「ファイルに保存」から保存先を選びます。
- 共有ドライブの場合も、iPhoneの「ファイル」から選べる場所へ保存し、ダウンロードを完了させます。ファイルの拡張子は変更しません。

## 4. iPhone版で取り込む

- iPhone版の「データ管理」→「データを取り込む」を押します。初回は起動時の「データを取り込む」からも開始できます。
- iPhoneの「ファイル」から、保存した.hakamapファイルを選びます。
- すでにデータがある場合は、全件置き換えの確認が表示されます。更新する場合は確認画面で置き換えを承認します。
- 「取り込み完了」と表示されたら、データ管理を閉じて配置図を確認します。

## 5. 取り込んだ内容を確認する

- Windows版と配置図・背景・墓所名が同じか確認します。「データ作成」の日時はWindowsでエクスポートした日時です。
- 検索対象を「墓所名・家名」または「人物の氏名」に切り替えて検索します。
- 該当するお墓をタップすると墓所名と登録された人物氏名が表示されます。人名検索に一致した氏名には「検索に一致」と表示されます。

## 6. データを更新する

- Windows版で編集・保存した後、もう一度エクスポートして同じ手順で取り込みます。家族も各自のiPhoneで取り込みます。
- iPhoneに保存する墓地は1つです。取り込みは追加・結合ではなく全件置き換えで、自動同期はありません。
- ファイル選択や置き換えをキャンセルした場合、または取り込みに失敗した場合は、以前のデータをそのまま使えます。

## ご利用上の注意

- 元の.hakamapは保管してください。サイトデータの削除などで端末内の保存が失われた場合は、再取り込みで復元します。

- iPhone版は参照専用です。編集はWindows版で行います。取り込み後の検索・参照には通信は不要です。
- iPhoneに保存する参照データは配置図・背景・墓所名・人物氏名などです。添付資料・備考・戒名は表示しません。
- 初期版の上限はファイル32MiB、展開合計48MiB、背景の縦横各4096px、5,000墓所、20,000人物です。上限を超えるデータは取り込めません。

## うまく取り込めないとき

- ファイルが見つからない場合は、LINE等の添付から「ファイルに保存」したか、ダウンロードが完了したかを確認してください。
- 取り込みに失敗した場合は、Windows版で新しくエクスポートし直し、ファイル形式と容量を確認して再度選択してください。
- 内容が古い場合は「データ作成」の日時を確認し、最新のエクスポートファイルで置き換えてください。
