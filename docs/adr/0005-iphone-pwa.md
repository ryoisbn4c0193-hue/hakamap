# ADR 0005: iPhone版をPWAとして配布する

日付: 2026-10-23
状態: 採用（利用者指定）

## 背景

Expo Go上の基本動作確認を完了したが、利用者はApple Developer Programへ加入せず、
Windows PCで開発し、iPhoneのホーム画面から起動してオフラインで参照したい。

## 決定

- `mobile/`のReact Native画面をReact Native Webで再利用し、静的なPWAとして配布する。
- 配布の主方式をPWAへ変更する。EAS・Apple署名は通常の導入手順に使用しない。
- 初回の配布プログラム取得・更新にはHTTPS接続を使う。通常の検索・参照は端末内で完結する。
- Service Workerでビルド時の静的ファイル一覧を事前保存する。全ファイルの保存成功後に利用可能と表示する。
- 更新版は保存完了後に待機し、利用者の「更新を適用して再起動」で切り替える。取り込み中は更新不可。
- 元の`.hakamap`はFile APIで読み、既存の検証処理を通して必要な情報だけ保存する。
- PWAはIndexedDBを使用する。地図と背景の単一レコードをreadwriteトランザクションで全件置換し、
  完了前には画面を切り替えない。名前表示設定は別レコードで保持する。
- 初回はホーム画面に追加したPWA内で取り込む。Expo GoとSafariの保存領域からの自動移行はしない。
- アーカイブ・背景・氏名・検索語は配布サーバーへ送らない。同期、テレメトリー、外部地図は追加しない。
- 対応目安はiOS 17以降のSafari・ホーム画面Webアプリ。実際の対応は実機で確認する。

## 影響

ADR 0004のWindows側の制約・既存エクスポート形式・参照専用の要件は維持する。
SQLite・Expo DOM・Apple署名は残してあるネイティブ実装の方式であり、PWAでは使用しない。
PWAは通常のiOSネイティブIPAとは異なり、OSや利用者によるサイトデータ削除で保存が失われる可能性がある。
永続ストレージを要求するが保証とは扱わず、元ファイルを保持し再取り込みで復元する。
配布URLのオリジン・パスは固定する。URLを変えると保存領域やホーム画面の登録先が変わることがある。
初回インストール・配布サイト公開・実機での完全終了後のオフライン試験を製造検査から区別する。
