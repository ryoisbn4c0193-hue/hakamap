# ADR 0004: iPhone参照アプリと既存エクスポートの直接取り込み

日付: 2026-10-23
状態: 採用

## 背景

Windowsで管理する墓地の配置図と名前を、本人と家族が現地でiPhoneから参照したい。
利用者からReact Native / Expoによる参照専用アプリ、オフライン保存、
既存`.hakamap`をそのまま渡す運用が指定された。

## 決定

- Windowsアプリは既存の構成・保存方式を維持し、同じリポジトリの`mobile/`にiPhone版を置く。
- Windowsの既存エクスポートを直接取り込み、検証後に必要な参照情報だけ抽出する。
- 専用エクスポート形式と変換ツールは設けない。
- iPhone版はローカル検索とSVG描画を行い、実行時のJava APIやネットワークに依存しない。
- 日本語変換確定の判定には同梱したExpo DOMの検索欄を使用する。
- 保存はExpo SQLiteのトランザクションで参照データを全件置き換える。
  データ管理・移送の正はWindows版に置き、iPhoneから編集・同期しない。
- iPhone初期版は縦向きのみとし、実機テストと配布用署名を製造完了から区別する。

## 影響

Windows向けのJava保存モデル・MUI・PixiJSの規約はWindows実装に適用し、
iPhone UIと端末内の参照コピーにはReact Native・SVG・SQLiteを使用する。
Windows版へSQLiteやモバイル依存を追加しない。
参照専用アプリは添付・備考・戒名を保持しないが、取り込み時には全収録ファイルを検証する。
初期版の容量・画像上限と、実機での確認事項は基本設計・実装状況に明記する。
