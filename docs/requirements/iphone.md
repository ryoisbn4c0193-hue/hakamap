# iPhone版の要件整理

更新日: 2026-10-23

## 現在の状態

iPhone版の設計・要件整理を開始した。以下は利用者との会話で確認した内容であり、
初期版の製造を完了し、0.1.2で利用者による実機の基本動作確認も完了した。実装範囲と未検証事項は
[実装状況](../design/iphone-implementation.md)を参照する。
既存のWindows版に対する要件・設計は維持し、この文書はiPhone版に適用する。

## 開発方針

- Windows版を維持し、同じリポジトリの`mobile/`に参照専用アプリを追加する。
- React Native、Expo、EAS Buildを使用する。
- 初期版はiPhoneの縦向きのみ対応する。横向きとiPad対応は初期版の対象外とする。
- Windows版の配色、配置図の表現、および操作感を引き継ぐ。
- Windows版でデータをエクスポートし、iPhone版でインポートして参照する。
- Windows版の既存エクスポート（`.hakamap`）をiPhone版で直接読み込む。
- 専用エクスポートや変換操作は不要。参照に必要な情報だけを端末内へ保存する。

## 確認済みの業務要件

- 利用者は本人と信頼する家族。墓地を訪れた際に目的のお墓を探す。
- 各自のiPhoneにアプリとデータを入れる。アプリ独自のパスワード・Face ID認証は不要。
- Windows版の配置図を利用し、お墓の位置と入口などの目印を表示する。
- GPSによる現在地表示は不要。指で拡大・縮小し、ドラッグで移動できる。
- 配置図上の名前・家名は、利用者が表示・非表示を切り替えられる。
- 名前・家名は初回は表示し、その後は前回の表示設定を次回起動時にも引き継ぐ。
- お墓をタップすると、墓所名・家名と登録された人物の氏名を参照できる。
- 人名検索に一致する氏名には「検索に一致」と表示し、墓所との対応を確認できる。
- 墓所名や人物氏名が未登録の場合は、その旨を表示する。
- 詳細表示は読み取り専用とし、「閉じる」で地図へ戻る。ドラッグや複数指操作では開かない。
- 名前・家名の部分一致で検索し、一致するお墓をすべて配置図上で強調表示する。
- 人物の氏名も検索対象とし、一致した人物が所属するお墓を強調表示する。
- 検索欄の近くに対象選択のプルダウンを置き、「すべて」「墓所名・家名」
  「人物の氏名」から選択できる。初期値は「すべて」とする。
- 「すべて」は墓所名・家名と人物氏名を対象とする。同じお墓に複数一致しても1件と数える。
- 検索は文字を入力するたびに結果を更新する。
- 日本語の変換中は検索せず、文字が確定したら検索結果と配置図の表示位置・倍率を更新する。
- 検索時は、該当するお墓が見える位置・倍率へ自動調整する。
- 複数のお墓が一致した場合は、該当するすべてのお墓が画面内に収まるよう自動調整する。
- 検索を解除した場合は、現在の配置図の表示位置・倍率を維持する。
- 「全体表示」ボタンで、いつでも墓地全体が収まる表示へ戻せる。
- 検索結果が0件の場合は「該当するお墓はありません」と表示し、現在の位置・倍率を維持する。
- 読み仮名検索は不要。
- データがある場合、起動時は墓地全体の配置図と検索欄を表示する。
- データがない場合、インポートの案内を表示する。
- LINEや共有ドライブなどでエクスポートファイルを受け取る。
- Windows版のデータを正とし、インポート時は全件置き換える。
- データ更新前に「現在のデータを置き換えます。よろしいですか？」と確認し、
  利用者が承認した場合に置き換える。
- インポート失敗時は、それまでのデータを保持する。
- 取り込んだデータの作成日時を表示する。
- データ管理画面に「データを取り込む」ボタンと、取り込み済みデータの作成日時を表示する。
- 取り込みは「データを取り込む」からiPhoneの「ファイル」でファイルを選択し、
  既存データがある場合は置き換え確認を経て、完了を案内する。
- LINEで受け取ったファイルは、いったん「ファイル」に保存してから選択する。
- 保存する墓地は1つ。更新時は各自で最新ファイルをインポートする。
- データと配置図を端末内に保存し、参照時の通信は不要。自動同期は行わない。
